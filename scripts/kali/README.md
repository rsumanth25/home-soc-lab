# Nmap Network Scanner

## Purpose
Automated network scanning utility for the Home SOC Lab.

## Technology
- Kali Linux
- Bash
- Nmap

## Features
- Accepts a target IP address.
- Performs service and version detection.
- Generates timestamped scan reports.
- Saves results automatically.

## Usage

```bash
chmod +x network-scan.sh

./network-scan.sh 127.0.0.1
