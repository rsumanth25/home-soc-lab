# Sysmon Investigation Findings

## 1. Process Creation – Event ID 1

**Test performed:** Started Notepad using PowerShell.

**Command:**
```powershell
Start-Process notepad.exe
```

**Observations:**
- Sysmon generated a Process Create event.
- Captured the executable path and process ID.
- Recorded command-line information and user context.
- Parent process information was available for investigation.

**Security relevance:** Helps analysts investigate suspicious process execution and parent-child process relationships.

## 2. Network Connections – Event ID 3

**Test performed:** Generated network activity and enabled Sysmon network connection monitoring.

**Command:**
```powershell
Test-NetConnection example.com -Port 443
```

**Observations:**
- Event ID 3 appeared after enabling the NetworkConnect rule.
- Network connection records included process, protocol, source and destination information.
- An inspected event showed a UDP connection to port 53, associated with DNS activity.

**Security relevance:** Helps analysts investigate unexpected network communication and identify the processes responsible.

## 3. File Creation – Event ID 11

**Test performed:** Enabled file creation monitoring and created a test file.

**Command:**
```powershell
New-Item "$env:USERPROFILE\Desktop\sysmon\SOC_Test_File.txt" -ItemType File
```

**Observations:**
- Sysmon generated Event ID 11 records.
- Inspected events included the creating process and target filename.
- One inspected event showed Chrome creating a file in its IndexedDB directory.
- The test file was successfully created and recreated, but its specific Event ID 11 record was not independently confirmed.

**Security relevance:** Helps analysts monitor file creation and investigate unexpected files or suspicious application activity.

## 4. DNS Queries – Event ID 22

**Test performed:** Enabled DNS query monitoring and queried example.com.

**Command:**
```powershell
Resolve-DnsName example.com
```

**Observations:**
- Sysmon generated Event ID 22.
- QueryName recorded example.com.
- QueryStatus was 0.
- PowerShell was identified as the querying process.
- DNS resolution results included IPv4 and IPv6 addresses.

**Security relevance:** Helps analysts investigate unusual domain lookups and potential command-and-control communication.

## 5. Overall Findings

The lab successfully demonstrated collection and basic investigation of four Sysmon event types:

- Event ID 1 – Process Creation
- Event ID 3 – Network Connection
- Event ID 11 – File Creation
- Event ID 22 – DNS Query

These events provide useful endpoint telemetry for security monitoring and incident investigation.

## 6. Limitations

- Monitoring was performed on a personal Windows 11 Home system.
- The configuration is a basic lab configuration, not an enterprise detection policy.
- Not every captured event was generated by a controlled test.
- No malicious activity or malware execution was performed.
- Splunk integration and automated detection rules are future work.
