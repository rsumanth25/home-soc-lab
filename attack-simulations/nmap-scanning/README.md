# Network Reconnaissance and Scanning Using Nmap

## Project Overview
This module focuses on network reconnaissance and TCP port scanning using Nmap in a Kali Linux environment. It is part of the Home SOC Lab project.

## Objectives
- Understand network reconnaissance.
- Identify active hosts.
- Discover open, closed and filtered ports.
- Identify running services and versions.
- Automate network scanning using Bash.
- Document and analyze scan results.

## Tools Used
- Kali Linux
- Nmap 7.991
- Bash
- VirtualBox

## Activities Performed
1. Nmap installation and verification.
2. Localhost TCP port scanning.
3. Full TCP port scanning.
4. Service and version detection.
5. Host discovery on the VirtualBox NAT subnet.
6. Automated scanning using a Bash script.

## Project Files
- `findings.md` – Scan findings and analysis.
- `kali-local-scan.txt` – Initial localhost scan.
- `all-ports-scan.txt` – Full TCP port scan.
- `host-discovery.txt` – Host discovery output.

## Screenshots

## Scope
Initial testing was conducted against the Kali Linux localhost and the VirtualBox NAT environment. Windows endpoint scanning will be performed after the Windows VM and isolated SOC network are configured.

## Disclaimer
All scanning activities are intended for authorized lab environments and educational purposes.
