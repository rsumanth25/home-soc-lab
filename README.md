# Home SOC Lab

## Overview
A hands-on Security Operations Center lab built using Oracle VirtualBox, Kali Linux, Windows 11 and Splunk.

The project focuses on network reconnaissance, endpoint monitoring, security event detection, log analysis and incident investigation.

## Lab Components

| Component | Technology |
|---|---|
| Attacker machine | Kali Linux |
| Target endpoint | Windows 11 |
| SIEM | Splunk Enterprise |
| Endpoint monitoring | Sysmon |
| Network scanning | Nmap |
| Network analysis | Wireshark |
| Web security testing | Burp Suite |

## Project Modules

1. Network Reconnaissance and Scanning using Nmap
2. Network Traffic Analysis using Wireshark
3. Web Application Security Assessment using Burp Suite
4. Windows Endpoint Monitoring using Sysmon
5. SIEM Deployment and Log Analysis using Splunk
6. Security Event Detection and Incident Investigation

## Current Progress

- Kali Linux environment configured.
- Nmap installation and initial scanning exercises completed.
- Bash-based Nmap scanning automation created.
- Windows endpoint deployment and Splunk integration planned.

## Repository Structure
